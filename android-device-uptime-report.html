Getting an uptime report shouldn't need a computer

Android has an uptime value buried in Developer options, and a boot log only ADB can read. Neither is something a regular user, or most administrators without a laptop in hand, can check.

RebootMonitor turns that raw system value into an actual report: readable on the device, in seconds, by whoever needs it.

Frequently asked questions

Can I export the uptime report as a file?

Not currently. The report is designed to be read on the device itself, in line with RebootMonitor keeping all data local rather than generating files or sending data elsewhere.

How far back does the report go?

Up to 12 months. The history and monthly heatmap cover the full year, and older entries are cleaned up automatically after that.

Does the report reset if I reinstall the app?

Reboot history is stored in the app's local database, so a normal update keeps it intact. A full uninstall removes it, since it is never backed up off the device by design.

Is this the same as the uptime shown in Android Settings?

It's calculated from the same system uptime value, but RebootMonitor surfaces it clearly on a dedicated screen along with history and trends, instead of a single line buried in Settings or Developer options.
