Finding out when your phone last restarted

It sounds simple, but Android doesn't make it obvious. There are three ways to find out.

Knowing when a phone last restarted helps when it feels slow, when an update asks for a restart, or when you look after shared devices that nobody remembers restarting.

1. Look in your phone's settings

Some Android phones show an Up time value under Settings → About phone → Status information. It tells you how long the phone has been running since it last started.

This is not available on every phone. It also shows only the current uptime, not the date of the restart, and it does not list earlier restarts.

2. Ask the device with ADB (for developers and IT)

If USB debugging is switched on and the phone is connected to a computer, the command adb shell uptime prints how long the device has been running. That works well for a technician, but it is not practical for everyday use.

Frequently asked questions

Can I see when my Android phone last restarted without an app?

Sometimes. Some phones show an Up time value under Settings, About phone, Status information. Developers can also run adb shell uptime from a computer. Neither lists earlier restarts.

What is Android uptime?

Android uptime is how long a device has been running since its last restart. RebootMonitor shows it on the dashboard together with the date and time of the latest reboot.

Does putting the phone to sleep or turning off the screen count as a restart?

No. A restart means the phone was switched off and started again, or was restarted from the power menu. Locking the screen or letting the phone sleep does not reset the uptime.

Does RebootMonitor need an internet connection?

No. RebootMonitor works completely offline and stores your reboot history on the device.
